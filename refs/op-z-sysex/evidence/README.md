# Evidence policy

The public repository carries protocol conclusions and confidence levels in the
documentation, but does not distribute the underlying private captures.

Excluded material includes firmware and app binaries, stock/factory projects,
project backups, project-bank dumps, MIDI captures, logs, audio, samples,
private paths, device identifiers, and machine reports derived from them.

New public evidence should be synthetic and minimal, or a human-written
description of a reproducible experiment that contains no copyrighted content.
